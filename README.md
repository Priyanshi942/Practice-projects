# 🎮 Simon Game

A simple memory-based game built using HTML, CSS, and JavaScript.  
Repeat the color sequence and test your memory!

---

## 🚀 How to Play
- Press any key to start
- Watch the color sequence
- Repeat the sequence by clicking buttons
- Each level increases difficulty
- Wrong move → game resets

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

---

## ✨ Features
- Interactive UI
- Increasing levels
- Simple game logic

---

## 📂 Project
Simon Game using DOM manipulation and event handling in JavaScript.
